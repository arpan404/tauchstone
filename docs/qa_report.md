## 5. Prereg guard. PASS with finding F-02

`tests/leakage/test_prereg_guard.py`. The guard refuses an unfrozen status and an
uncommitted copy, and the real frozen file passes (`sha256 21f7460e…bb8a3`, matching
the integrity log). **F-02 (minor, for the lead).** The first `git rev-parse`
