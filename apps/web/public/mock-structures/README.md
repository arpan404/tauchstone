# Mock structure for offline demo use (mock mode only)

`1crn.cif` is the mmCIF file for PDB entry 1CRN (crambin, 46 residues),
downloaded from https://files.rcsb.org/download/1crn.cif on 2026-11-05.

Public domain structural data (RCSB PDB). Used only as a lightweight,
offline-capable example structure for the Mol* protein-viewer panel in
mock mode. It is NOT evidence for any candidate: the viewer caption always
reads "Target context only. Not evidence that the drug binds this structure."

Source: RCSB Protein Data Bank, entry 1CRN
(Teeter, 1984 — small-molecule-free plant seed protein, chosen for its tiny size).
