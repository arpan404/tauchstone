# Mock structure for offline demo use (mock mode only)

`1crn.cif` is the mmCIF file for PDB entry 1CRN (crambin, 46 residues),
downloaded from https://files.rcsb.org/download/1crn.cif on 2026-11-05.

It is public domain structural data from the RCSB PDB. The Mol* protein-viewer panel uses it
in mock mode as a small example structure that loads offline. It is not evidence for any
candidate. The viewer caption always reads "Target context only. Not evidence that the drug
binds this structure."

Source: RCSB Protein Data Bank, entry 1CRN (Teeter, 1984). Crambin is a plant seed protein
with no bound small molecule, chosen because it is tiny.
